# ADR-0002: 文件公开访问统一走 Shares 表

## 状态
accepted

## 上下文

需要支持文件公开分享，存在两种模型：

**模型 A: 文件级 ACL**
- 文件记录包含 `visibility` 字段（私有/内部/公开）
- 需要 `file_permissions` 和 `permission_inheritance` 表
- 临时码可限定只能访问特定文件夹

**模型 B: 统一 Shares 表**
- 文件始终私有
- 公开访问必须通过 `shares` 表创建分享链接
- 分享类型：page（分享页）/ direct（直链）

## 决策

选择模型 B：文件始终私有，公开访问统一走 `shares` 表。

## 后果

**正面：**
- 权限模型简单清晰，易于审计
- 避免复杂的权限继承计算
- 分享链接可独立管理（密码、次数、过期）
- 单管理员模式足够满足需求

**负面：**
- 无法直接设置文件为"公开"状态
- 需要额外步骤创建分享链接

## 替代方案

**模型 A: 文件级 ACL**： rejected，单管理员模式过度复杂，权限继承计算困难

**混合模型**： rejected，状态不一致风险
